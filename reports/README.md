# Optimization Reports & Weekly Review

Each report here is a dated set of proposed changes — new keywords, negative
keywords, bid/budget tweaks, ad copy swaps — generated from whatever data is
available (web research initially; real Search Terms/Keyword exports from
`data/search-term-reports/` once you start sharing them).

## How review works

1. A report is added/updated here whenever there's something worth reviewing.
2. Every recommendation is written as a checkbox: `- [ ] Add "..." as exact
   match negative — 0 conversions / 340 clicks last 30 days`.
3. You review and reply with approvals/rejections (or just check the boxes
   and say "approved" if you're working directly in this repo).
4. Approved changes get applied manually in the Google Ads UI (no live
   Ads connector is wired up yet — see root `README.md`), then marked done.

## Weekly reminder

A recurring check-in is scheduled to prompt review of any open items in this
folder. If a week goes by with nothing new to review (e.g. no export was
shared), that check-in is a no-op — you won't be pinged for nothing.
