# Drop Google Ads exports here

To get real (not just researched) optimization recommendations, export and
drop these CSVs here periodically (weekly ideal, biweekly minimum):

1. **Search terms report** (Campaigns > Insights and reports > Search terms) —
   the actual queries triggering your ads. This is the single most useful
   report: it surfaces new negative keywords and new keyword opportunities.
2. **Keywords report** — impressions, clicks, CTR, CPC, conversions per keyword.
3. **Campaign performance report** — spend, conversions, CPA per campaign.

Name files with the date range, e.g. `search-terms-2026-09-01_2026-09-07.csv`.

Once a file lands here, it gets turned into a dated report under `reports/`
with specific add/pause/negative recommendations for your approval.
